Use at your own riskUse por sua conta e risco

Dragonize writes settings to your device's memory, like the official software does. Damage to the mouse or keyboard is very unlikely but not impossible. The authors are not responsible for any problem, and there is no warranty.

O Dragonize grava configurações na memória do aparelho, como o software oficial. Danos ao mouse ou teclado (como queimar o aparelho) são muito improváveis, mas não impossíveis. Os autores não se responsabilizam por problemas, e não há garantia.

Everything the Windows app does, on LinuxTudo que o app de Windows faz, no Linux

Redragon only ships configuration software for Windows. Dragonize talks to the device directly over USB, keeps the familiar look, and needs no background service. A Redragon só oferece software de configuração para Windows. O Dragonize conversa direto com o aparelho via USB, mantém o visual conhecido e não precisa de serviço em segundo plano.

Install in one minuteInstale em um minuto

No package manager and no root install. Just one file. Sem gerenciador de pacotes e sem instalar como root. Só um arquivo.

Download Dragonize-x86_64.AppImage.

Baixe o Dragonize-x86_64.AppImage.

Make it executable and run it.

Torne executável e rode.

chmod +x Dragonize-x86_64.AppImage ./Dragonize-x86_64.AppImage

The first time, Dragonize offers to install a small udev rule so your user can talk to the device. Your desktop asks for the admin password once. Or do it from a terminal:

Na primeira vez, o Dragonize oferece instalar uma pequena regra udev para seu usuário falar com o aparelho. O desktop pede a senha de administrador uma vez. Ou faça pelo terminal:

./Dragonize-x86_64.AppImage --install-udev-rule
